  Git review and staging preview.

  branches safely.
- [refactor-0-2-1](plans/refactor-0-2-1.md) — refactor the UI, harden
  mutations, and release version 0.2.1.
- [ui-navigation-0-3-0](plans/ui-navigation-0-3-0.md) — polish cockpit,
  search, diff navigation, and shortcut guidance for 0.3.0.
- [release-installation-0-3-1](plans/release-installation-0-3-1.md) — add the
  MIT license, user-local installation, and automated release notes for 0.3.1.
- [gitview-1-0-0](plans/gitview-1-0-0.md) — reach Lazygit v0.66.2 workflow
  parity with a polished Rust TUI and safe merge previews; defer AI.
